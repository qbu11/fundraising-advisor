# 融资顾问方法论

## 1. 融资准备度

把以下七项标为“已具备 / 需补强 / 关键缺口”，不要制造伪精确总分：

1. 问题与价值主张：客户、痛点、替代方案是否清楚。
2. 产品证据：产品能否演示，关键假设是否已验证。
3. 市场与竞争：切入点、差异和扩张路径是否可信。
4. 商业证据：收入、增长、留存、订单或试点是否匹配当前阶段。
5. 团队适配：是否覆盖产品、行业、销售和交付关键能力。
6. 融资逻辑：金额、用途、里程碑和下一轮价值提升是否连贯。
7. 材料与合规：BP、财务模型、股权结构、知识产权、重大合同和数据室是否可用。

给出最强的三项依据、最重要的三项缺口，以及“立即启动 / 小范围试水 / 延后准备”的建议和原因。

## 2. 融资额与里程碑

融资额从下一次价值跃迁倒推：

```text
融资需求 =
预计周期内净现金消耗
+ 一次性投入
+ 风险缓冲
- 当前可用现金
- 保守经营现金流
```

设计三个情景：

- 最低可行额：完成一个关键可验证里程碑。
- 目标融资额：覆盖核心计划和合理缓冲。
- 扩展融资额：仅用于加速已经验证的路径。

将每项资金用途映射为：

```text
资金 → 行动 → 可量化里程碑 → 时间 → 下一轮价值提升
```

通常按 12–24 个月规划，但应根据行业周期、现金消耗和收入确定性调整。用户没有提供估值时，不替用户给出虚假精确估值；只讨论影响因素、融资额与稀释的情景关系。

## 3. 融资叙事

用同一条逻辑链回答：

1. 为什么是这个问题？
2. 为什么是现在？
3. 为什么当前方案能赢？
4. 已经证明了什么？
5. 最大的未验证风险是什么？
6. 这轮资金将把公司带到什么可验证状态？
7. 为什么该状态值得下一轮资本继续投入？

所有数字区分实际、预测和目标。对未知问题承认未知并给出验证计划。

## 4. 投资人筛选与排序

先宽召回，再做硬筛选和解释性排序。

硬筛选包括：

- 阶段明显不匹配；
- 已知票面与融资需求完全不重叠；
- 币种或地域无法兼容；
- 用户明确排除；
- 合规结论为 `risk`。

建议权重：

| 维度 | 权重 |
|---|---:|
| 赛道匹配 | 25% |
| 阶段匹配 | 20% |
| 金额与币种 | 15% |
| 个人经验和代表案例 | 15% |
| 机构能力与后续支持 | 10% |
| 数据可信度与时效 | 10% |
| 暖介绍路径 | 5% |

数据库分数、历史评价数或合规字段不能单独决定排序。每位候选必须列出匹配理由、主要疑点、联系前核验项、数据时间和建议切入话题。

## 5. 接触节奏

不要逐个串行，也不要一次群发全部候选。

1. 校准波：5–8 名较匹配但非最关键候选，用于测试故事和常见问题。
2. 核心波：根据反馈更新材料后，在紧凑窗口接触 10–20 名核心候选。
3. 扩展波：邻近赛道、产业资本、区域基金或能提供关键资源的候选。
4. 回访波：仅在有真实新增客户、收入、产品或团队进展时回访。

不得制造虚假热度、虚假截止日期或不存在的竞争性报价。

## 6. 聊天策略

### 冷启动

```text
称呼 + 具体联系原因
一句话项目与目标客户
一个最强且可验证的进展
本轮融资目标和匹配原因
低压力、明确的下一步
```

### 暖介绍

给介绍人一段可直接转发的 100–150 字摘要，说明创始人、项目、核心进展、匹配原因和具体请求。未经同意不得使用介绍人的姓名或把普通认识说成背书。

### 首会

30 分钟参考结构：

1. 议程和对方关注点，2 分钟。
2. 问题、客户和解决方案，5 分钟。
3. 产品或场景，5 分钟。
4. 进展、增长和单位经济，5 分钟。
5. 市场、竞争和差异，4 分钟。
6. 团队，3 分钟。
7. 融资额、用途和里程碑，3 分钟。
8. 对方流程、问题和下一步，3 分钟。

### 异议

使用：

```text
确认异议 → 判断类型 → 给出证据 → 承认未知 → 提出验证方案 → 确认下一步
```

不要临时改写数据迎合投资人，不攻击竞争对手，不试图压服合理异议。

### 跟进

会后 24 小时内发送问题复述、补充材料、双方确认的下一步和时间。无回复时最多进行两次有新增信息的跟进；明确拒绝或要求停止后必须停止。

## 7. 事实与伦理

- 数据库是候选发现来源，不证明当前任职、额度或投资意愿。
- 不虚构客户、收入、融资进展、背书、共同关系或投资意向。
- 不把会面、尽调或索取材料表述为投资承诺。
- 不泄露联系方式、数据室、客户名单、内部条款和第三方隐私。
- 不根据无关敏感属性筛选或个性化。
- 对外消息发送前核对事实、数字、称谓、收件人和介绍授权。
- 输出属于决策辅助，不构成投资、财务、法律或税务意见。
